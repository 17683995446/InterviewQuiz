# InterviewQuiz 项目需求文档 (SRS)

## 1. 项目概述

### 1.1 项目背景
随着AI和计算机行业的快速发展，面试竞争日益激烈。求职者需要一个高效、专业的刷题工具来准备面试。InterviewQuiz 应运而生，提供海量的高质量面试题目和良好的学习体验。

### 1.2 项目目标
- 提供 **5000+** 道高质量AI/计算机岗位面试选择题
- 覆盖 **8大技术领域**
- 支持分类学习、难度筛选、进度追踪
- 提供流畅、专业的用户体验

### 1.3 目标用户
- 计算机科学专业学生
- AI/ML工程师求职者
- 软件开发工程师
- 技术面试候选人

---

## 2. 功能需求

### 2.1 核心功能

#### 2.1.1 题库管理
- ✅ 题库数据模型（题目、选项、答案、解析、分类、难度）
- ✅ 分类管理（算法、Java/Kotlin、数据库、网络、Android、OS、AI/ML）
- ✅ 难度分级（EASY、MEDIUM、HARD）
- ✅ 题目数量：120道（可扩展至5000+）

#### 2.1.2 学习功能
- ✅ 题目浏览和搜索
- ✅ 按分类筛选
- ✅ 按难度筛选
- ✅ 组合筛选（分类+难度）
- ✅ 答题功能（选择题交互）
- ✅ 即时反馈（正确/错误）
- ✅ 详细解析展示

#### 2.1.3 用户界面
- ✅ Material Design 3 设计
- ✅ 深色/浅色主题支持
- ✅ 响应式布局
- ✅ 流畅的动画效果

### 2.2 扩展功能（未来版本）

- [ ] 学习进度统计

#### 2.2.2 社交功能
- [ ] 收藏功能
- [ ] 笔记功能

#### 2.2.3 高级功能

## 3. 非功能需求

### 3.1 性能需求
- 启动时间：< 2秒
- 页面切换：< 100ms
- 题库加载：< 1秒（120题）
- 内存占用：< 100MB

### 3.2 兼容性需求
- 最低支持：Android 7.0 (API 24)
- 目标平台：Android 14 (API 34)
- 屏幕适配：手机、平板

### 3.3 质量需求
- 代码覆盖率：> 60%
- 无致命Bug
- 遵循Material Design规范

## 4. 技术架构

### 4.1 技术栈
- **语言**：Kotlin 2.0
- **UI框架**：Jetpack Compose
- **架构模式**：MVVM
- **依赖注入**：Hilt
- **数据库**：Room
- **异步编程**：Kotlin Coroutines
- **构建工具**：Gradle 8.2

### 4.2 系统架构
```
┌─────────────────────────────────────┐
│           UI Layer                  │
│  (Jetpack Compose + ViewModel)     │
├─────────────────────────────────────┤
│         Domain Layer               │
│      (Business Logic)              │
├─────────────────────────────────────┤
│          Data Layer                │
│  (Repository + Room Database)      │
└─────────────────────────────────────┘
```
